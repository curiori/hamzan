## 目的

`docs/superpowers/specs/2026-11-04-hamzan-juku-units-design.md` のとおり、ステージ6〜9（28レベル）と「塾の単元」を入れる。今の61レベルの出題、判定、記録は変えない。

## 全体の決まり

* `src/domain` と `curriculum.json` は変えない。`bun run test:domain` は通ったまま
* テストが読むモジュール（`src/juku`、`src/course`、`src/state` の store.ts 以外、`src/features` の純粋な補助）は react-native と Expo を import しない
* 保存の形は足すだけ（Profile の `juku` は省略できる）。persist の version は 2 のまま
* 子ども向けの文言はひらがな中心。問題文の漢字にはふりがなを付ける
* 各タスクの終わりに、関係するテストを通してからコミットする（Conventional Commits、末尾に絵文字と `- Generated by Copilot`）

## タスク

### Task 1: 塾の単元の学習エンジン（`src/juku`）

* `num.ts`（小数と分数を正確に計算）、`units.ts`（単位の表）、`benchmarks.ts`（身近な量の表）
* `juku.json` と `spec.ts`（仕様の型と検査）
* `problem.ts`（問題と答えの形、表示のトークン、読み上げ、答え、fact key、書く桁数）
* `generators.ts`（28レベルの出題と、列挙できるレベルの全問題）
* `scaffolds.ts`（ヒントの空欄と行、メモ、絵のヒントの中身）
* `judge.ts`（判定、約分・形の注意、ミスの種類）
* `track.ts`（単元を開く・閉じる、チェック、塾の frontier と pending、前提に戻る、ステージチェック）
* テスト：`tests/juku/*.test.ts`。28レベル×2,000問で、答えを別の計算で確かめ、ヒントの最後の空欄が答えに一致し、メモがヒントの空欄にあり、D が出題の平均と0.2以内

### Task 2: まとめて扱う層（`src/course`）

* レベルとステージの引き当て（`courseLevel`、`courseStage`、子ども向けの名前）
* 問題の振り分け（表示の文字、答えの文字、判定、インスタンスづくり、ミスの種類）
* セットの組み立て（レベル、ミックス、ウォームアップ）と目安の時間（R を足した式）
* 進み方（`lpOf` と `statusOf` の全レベル版、マスターしたレベルの一覧、チャレンジ）
* きょうの れんしゅうの組み立て（`planDay`）と、区切りの解決
* テスト：今の61レベルでは domain の関数と同じ結果、塾の単元を開いたときの区切り

### Task 3: 記録とセッション

* `src/state/types.ts`：問題と答えとミスの種類の型を広げる、`juku`、`juku_check`、区切りの型
* `src/state/profile.ts`、`record-set.ts`、`create-store.ts`、`src/session/requests.ts`、`src/game/economy.ts`
* 保護者の操作：単元を開く・閉じる（その日の練習をまだ始めていなければ組み直す）
* テスト：`tests/state/record-set.test.ts`、`tests/state/store.test.ts`、`tests/session/requests.test.ts` に足す

### Task 4: 出題の画面

* キー：小数点、つぎ、選択肢、○×の言葉
* 答え欄：小数、分数（帯分数）、2つの数、単位
* 塾の単元の問題文（ふりがな、分数、文章）と絵のヒント（3.14の段、百分率の表、数の線、身近な量）
* 解き方の部品（答えだけ、ヒント、メモ）
* テスト：`tests/features/field-set.test.ts` と、塾の単元のヒントの流れ

### Task 5: ちず、結果、保護者の画面

* ちず（ステージ6〜9、鍵、塾の frontier の枠）、レベルのシート、きょうの れんしゅうの区切りの名前
* 結果の画面（チェックの結果）
* 保護者の画面の「塾の単元」タブ、ダッシュボード（ステージ0〜9、ミスの種類8つ）、アプリ情報
* テスト：`tests/features/dashboard-data.test.ts` などに足す

### Task 6: 文書と確認

* README（89レベル、塾の単元）、AGENTS.md（テストが読むモジュールの一覧）
* `bun run typecheck`、`bun run lint`、`bun test`、`bun run test:domain`、`bun run export:ios`
* web 表示で、小数点のキー、分数のマス、4択、○×、文章の問題、保護者の画面の「塾の単元」を確かめる
