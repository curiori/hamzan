# ハムざん Expo 版 土台とロジック移植 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Web 版のリポジトリを Git 管理し、Expo SDK 54 のアプリに置き換え、画面以外の学習ロジック（記録、保存、セッション、時計、効果音）を React Native で動く形に移植する。

**Architecture:** 学習エンジン `src/domain` は変更しない。Web 版の `store.ts` と `pages/home.tsx` のロジックを、React Native に依存しない純粋な TS（`src/state`、`src/session`、`src/platform/active-clock.ts`）と、薄い端末依存部分（AsyncStorage、expo-audio、expo-haptics）に分ける。Web 版のソースは削除し、移植元はタグ `web-prototype` から `git show` で読む。

**Tech Stack:** Expo SDK 54（React Native 0.81、React 19.1、Expo Router 6）、TypeScript、zustand、AsyncStorage、expo-audio、expo-haptics、Bun（パッケージ管理とテスト）

**Spec:** `docs/superpowers/specs/2026-10-29-hamzan-ios-design.md`

## Global Constraints

- Expo SDK は 54 に固定する（`expo@~54.0`）。ネイティブの依存は `bunx expo install` で入れ、`expo@latest` へは上げない
- Expo Go に入っているモジュールだけを使う
- この PC での依存の取得は `bun install --network-concurrency 4`
- `src/domain/` と `curriculum.json` は変更しない。ドメインテスト 4 本（golden、generators、scaffolds、rules）が常に PASS
- 記録は端末内だけ（AsyncStorage）。保存キーは `hamzan-ios-v1`
- 子ども向けの文言はひらがな中心
- import の別名は `@/*` → `src/*`
- テストは `bun test`（新規）と `bun run tests/domain/*.ts`（既存）。React Native を import するファイルは bun のテストから読まない
- コミットは Conventional Commits（英語、命令形、説明は 100 バイト未満）。本文の最後に「絵文字 - Generated by Copilot」、空行、`Co-authored-by: Copilot <223556219+Copilot@users.noreply.github.com>`

## Review Focus

- 保存データの読み込み完了前に操作すると、読み込みで上書きされる。読み込み完了の印（`hydrated`）が立つまでは画面を出さない前提で、ストアがその印を正しく立てることを Task 6 で確かめる
- 23:59 に始めて 0:01 に終えたセットでも落ちず、今日のセッションを誤って進めない（Task 5）
- こどもが複数いるとき、保護者画面の操作が選んだ子に効く（入力テストの保存先。Task 6）
- 一時停止中にバックグラウンドへ移っても、時間を二重に引かない（Task 8）
- 60 秒を超えてバックグラウンドにいたセットは判定しない（Task 5 と Task 8）
